# CODSOFT Java Internship Projects

This repository contains Java-based console applications developed as part of the OIB-SIP Internship.

---

## 1. Currency Converter

### Objective
To develop a program that converts currency values between INR, USD, and EUR.

### Features
- Convert INR to USD and EUR
- Convert USD to INR
- Menu-driven program
- User-friendly input handling

### Technologies Used
- Java
- Scanner class
- Switch-case

### Outcome
This project helped in understanding control statements, user input handling, and basic real-world application logic.

---

## 2. Number Guessing Game

### Objective
To create a game where the user guesses a randomly generated number.

### Features
- Generates random number between 1 to 100
- User inputs guesses
- Provides hints (too high / too low)
- Limited attempts
- Displays win or loss result

### Technologies Used
- Java
- Random class
- Scanner class

### Outcome
This project improved logical thinking and understanding of loops and conditional statements.

---

## 3. Student Result System

### Objective
To calculate total marks, average percentage, and grade of a student.

### Features
- Accepts marks for multiple subjects
- Calculates total and average
- Assigns grade based on performance
- Simple and efficient logic

### Technologies Used
- Java
- Scanner class
- Conditional statements
- Loops

### Outcome
This project helped in understanding basic calculations, loops, and decision-making in Java.
